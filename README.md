# Benefit Street
Play seven days on a fictional British estate. Make rent, guard your morale and earn favours from the neighbours.

Open index.html to play locally. Click a choice or press its number. Sound is optional. Progress saves in the current browser when local storage is available.

## GitHub Pages
Extract the archive and put its contents in the root of your GitHub repository, including index.html and street.webp. In Settings → Pages, choose Deploy from a branch, select your branch and /(root), then save. GitHub shows the game URL when deployment completes.

The game is static and all assets are bundled. Press Start 2P is included under the SIL Open Font License in FONT-LICENSE.txt.
