# Benefit Street

Play at https://punkychipp.github.io/benefitstreet/.

A six-week browser game set in West Shambles. Travel between five locations, work four playable jobs, take on neighbours’ favours and spend spare cash on shared projects. Each action uses a morning or evening. Rent falls due on Sundays. Work the pirate radio with Pat, bid at Val’s mystery auction or sample Babs’s dryers. Estate Reputation records four milestones in turns so friends can compare separate solo runs. At the verdict, choose a permanent upgrade and begin a new season. Upgrades and best milestone turns carry over. Existing four-week saves finish on their original schedule.

Open index.html locally or serve this directory as static files. No build or external dependencies. Progress saves in the current browser. The original seven-day game and its save are accessible via the Classic link.
